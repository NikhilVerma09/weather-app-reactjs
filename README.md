# REACT BASED WEATHER APP

This is a dynamic and responsive weather application built using React.js that allows users to get real-time weather data for their current location or any searched city across the globe.

## 📝Overview

This project is more than just a simple weather display; it's a comprehensive application that showcases advanced frontend development techniques like API integration, state management, and logic building. It's an excellent portfolio piece to demonstrate competence in modern JavaScript frameworks and asynchronous data handling.


## ✨Key Features

* **Real-Time Geolocation-Based Weather:** Automatically detects the user's current location to display the local weather, temperature, and time zone upon load, after seeking user permission. 

* **Dynamic City Search:** Users can search for weather conditions for any city worldwide using the search bar, which hits the external weather API. 

* **Detailed Weather Information:** Displays comprehensive data including:

    * Temperature (in Celsius)

    * Humidity

    * Wind Speed

    * Visibility 

* **Contextual UI:** The application uses dynamic icons and visual elements that change based on the current weather condition (e.g., sunny, smoky, cloudy, rainy).
  

  ## 💻Technologies Used

  * **Frontend :	React.js (Class Components)**	For building a component-based, interactive User Interface and managing application state.
    
* **API	: OpenWeatherMap API**	To fetch accurate, real-time weather data based on latitude/longitude or city name.
  
*  **Styling:	Custom CSS/External Images**	For dynamic background images (e.g., from Pexels/Unsplash) and custom styling.
  
* **Utility:	JavaScript Geolocation API**	To securely get the user's coordinates for initial weather display.
